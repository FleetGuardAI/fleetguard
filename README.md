# FleetGuard

> AI-Powered Fleet Operating System

FleetGuard is an AI-powered fleet operating system designed to help transport companies manage their entire fleet from a single platform.

## 🚀 Current Features

- Vehicle Management
- Driver Management
- Trip Management
- Fuel Management
- Expense Management
- Dashboard & Analytics
- AI Receipt Verification

## 🛠 Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- SQLite

### Frontend
- React
- Vite
- TailwindCSS

## 📌 Vision

FleetGuard aims to become the intelligence platform for commercial transportation by combining ERP, automation, analytics and intelligent decision support.
